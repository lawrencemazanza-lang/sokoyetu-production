# SokoYetu Mtaani Stage 26A: Soft Launch Order Checklist

Use this checklist for every real order during soft launch.

## Before fulfilment

- [ ] Order is visible in admin/order records.
- [ ] Customer phone number is available.
- [ ] Delivery address is available.
- [ ] M-PESA payment status is confirmed.
- [ ] M-PESA receipt/checkout reference is recorded if available.
- [ ] Seller has confirmed stock availability.
- [ ] Product price matches listing.
- [ ] Delivery method is agreed.

## During fulfilment

- [ ] Customer has been updated.
- [ ] Seller has prepared the item.
- [ ] Rider/courier/pickup method is confirmed.
- [ ] Customer has been contacted before dispatch.
- [ ] Delivery cost is agreed if applicable.

## After fulfilment

- [ ] Customer confirms receipt.
- [ ] Order marked delivered.
- [ ] Seller payout noted if applicable.
- [ ] Support issue recorded if any.
- [ ] Refund/cancellation handled if needed.
