# SokoYetu Mtaani Stage 37F: Flash Sale Themes and Cart Logo

This stage improves only the Flash Sale presentation and the SokoYetu Mtaani logo.

## Changes

```text
Each Flash Sale product receives its own themed gradient background.
The large live Flash Sale product changes background with each product.
Flash Sale mini cards use product/category-based backgrounds.
The old plain SY logo is replaced with a styled shopping cart logo.
```

## Test

```cmd
npm run stage37f:check
node --check server.js
npm run dev
```

Open:

```text
http://localhost:5173/
```

Check that the Flash Sale live product and mini products have different themed backgrounds.
