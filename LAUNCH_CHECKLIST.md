# SokoYetu Launch Checklist

## A. Core buyer checks

- [ ] Buyer can create account.
- [ ] Buyer can log in.
- [ ] Buyer can search products.
- [ ] Buyer can add product to cart.
- [ ] Buyer can checkout.
- [ ] Buyer can trigger M-PESA payment.
- [ ] Buyer can track order.
- [ ] Buyer can view legal/support pages.

## B. Seller checks

- [ ] Seller can create account.
- [ ] Seller can access Seller Studio.
- [ ] Seller can add product.
- [ ] Seller can upload product image.
- [ ] Seller can view orders containing seller products.
- [ ] Seller can update delivery status.
- [ ] Seller cannot access admin tools.

## C. Admin checks

- [ ] Admin can log in.
- [ ] Admin Centre opens.
- [ ] Admin can view users.
- [ ] Admin can view products.
- [ ] Admin can view orders.
- [ ] Admin can view payments.
- [ ] Admin can add wholesalers.
- [ ] Admin can add wholesaler products.
- [ ] Admin can import wholesale products with profit percentage.
- [ ] Admin AI Suite V2 opens.
- [ ] Wholesaler search returns supplier list.
- [ ] Admin tools are hidden from buyers and sellers.

## D. Payment checks

- [ ] M-PESA demo mode works.
- [ ] M-PESA Daraja sandbox credentials are added.
- [ ] STK Push reaches phone in sandbox.
- [ ] Callback updates payment status.
- [ ] Payment receipt is stored.
- [ ] Failed or cancelled payment updates order correctly.

## E. Production checks

- [ ] SQLite replaced with PostgreSQL.
- [ ] Local uploads replaced with Cloudinary, Amazon S3 or equivalent.
- [ ] HTTPS enabled.
- [ ] Real JWT secret set.
- [ ] Test accounts removed or secured.
- [ ] Legal pages reviewed.
- [ ] ODPC/data protection obligations reviewed.
- [ ] Backup process configured.
- [ ] Error logging configured.
- [ ] Final mobile responsiveness check completed.
