# Stage 34A: Launch Day Checklist

## Before launch

- [ ] Latest commit deployed on Render.
- [ ] Production domain opens.
- [ ] Certificate is valid.
- [ ] Homepage opens.
- [ ] Categories page loads products.
- [ ] Product detail page opens.
- [ ] Seller stores page opens.
- [ ] Help Center opens.
- [ ] Track Order page opens.
- [ ] Support Request page opens.
- [ ] Admin orders page opens.
- [ ] Support queue opens.
- [ ] M-PESA readiness reviewed.
- [ ] M-PESA environment guard reviewed.
- [ ] M-PESA reconciliation reviewed.
- [ ] Evidence export tested.
- [ ] Live test runbook ready.
- [ ] Incident response playbook ready.
- [ ] Backup/export checked.

## During launch

- [ ] Monitor Render logs.
- [ ] Monitor admin orders.
- [ ] Monitor support queue.
- [ ] Monitor M-PESA reconciliation.
- [ ] Record first buyer order.
- [ ] Record first successful payment evidence.
- [ ] Export evidence after first payment.
- [ ] Keep incident response page open.

## Hold or rollback if

- [ ] Public pages fail.
- [ ] Checkout does not load.
- [ ] STK Push fails repeatedly.
- [ ] Customer receipt exists but order remains unpaid.
- [ ] Amount mismatch appears.
- [ ] Render logs show callback errors.
- [ ] Admin cannot verify orders or payments.
- [ ] Support queue receives repeated payment complaints.
