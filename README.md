# SokoYetu Mtaani Elite Jumia-Inspired Marketplace

This is a clean static front-end prototype. It does not need npm install.

## Run on Windows Command Prompt

```cmd
cd "C:\Users\PC\Desktop\SokoYetu Mtaani\sokoyetu-elite-jumia-inspired"
npm run dev
```

Open the link shown, usually:

```text
http://localhost:5173/
```

## What is included

- Creative modern SokoYetu Mtaani logo using the initials SY.
- Jumia-inspired homepage organization while remaining original.
- Deals visible from the first screen.
- Compact Flash Sales Live section with countdown.
- One-at-a-time live streaming flash product with image, price, discount, and stock meter.
- Running advert banner.
- Live sellers icon and live seller list visible at the top.
- Smart buyer tools visible at the top for buyers.
- Account, Help, and Cart ordered correctly with Cart at the far right.
- Role-based views: buyer, seller, admin.
- Admin-only AI wholesale sourcing and digital selling tools.
- Seller-only live selling and seller dashboard tools.
- Buyer-only shopping assistant, wishlist, price alerts, cart and checkout.
- M-PESA checkout demo interface.
- Full footer with market description, quick links, categories and contacts.
