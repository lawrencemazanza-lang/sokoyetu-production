# SokoYetu Stage 27A: Seller Onboarding and Verification Guide

Stage 27A defines the seller onboarding workflow for soft launch.

This stage does not change checkout, M-PESA, DNS, email forwarding, database schema, product import or LiveKit logic.

## Seller onboarding flow

```text
Seller applies
→ Admin checks identity/contact details
→ Admin checks business/product category
→ Admin checks fulfilment ability
→ Admin approves, rejects, requests more information or suspends
```

## Seller statuses

Use these operational statuses:

```text
Application Received
Documents Requested
Under Review
Approved
Rejected
Suspended
```

## Minimum seller information

```text
Seller name
Business name
Phone number
Email address
Location
Product categories
Delivery/pickup ability
Sample product photos
Return/refund approach
```

## Soft launch rule

During soft launch, sellers should not publish products without admin review. Admin should verify seller details and product reliability before promotion.
