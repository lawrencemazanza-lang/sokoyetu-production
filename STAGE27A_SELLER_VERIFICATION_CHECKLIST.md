# SokoYetu Mtaani Stage 27A: Seller Verification Checklist

Use this checklist before approving a seller.

## Identity and contact

- [ ] Seller name recorded.
- [ ] Business name recorded.
- [ ] Phone number confirmed.
- [ ] Email address confirmed.
- [ ] Location recorded.
- [ ] Main contact person identified.

## Product and category

- [ ] Product categories are allowed.
- [ ] Product descriptions are clear.
- [ ] Product images are real or supplier-approved.
- [ ] Prices are realistic.
- [ ] Stock levels are confirmed.
- [ ] Warranty or return expectations are clear where relevant.

## Risk checks

- [ ] No counterfeit wording.
- [ ] No illegal or restricted product.
- [ ] No misleading claims.
- [ ] No suspicious payment request outside SokoYetu Mtaani.
- [ ] No pressure to bypass admin review.

## Fulfilment

- [ ] Seller can prepare item after paid order.
- [ ] Seller can support pickup, rider collection or delivery.
- [ ] Seller understands customer communication process.
- [ ] Seller agrees to admin order confirmation during soft launch.

## Decision

- [ ] Approved.
- [ ] More information requested.
- [ ] Rejected.
- [ ] Suspended.
